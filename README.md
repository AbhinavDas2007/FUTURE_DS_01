# Superstore Sales Analytics Dashboard

## Project Overview
This project analyzes Superstore sales data using Tableau Public to explore sales performance, profitability, product performance, and regional trends.

## Objectives
- Analyze sales trends over time.
- Compare sales across product categories and regions.
- Visualize state-level sales performance on a map.
- Identify top-performing products.
- Summarize key business metrics using KPI cards.

## Tools Used
- Tableau Public
- Superstore dataset

## Dashboard Features
- Total Sales
- Total Profit
- Average Order Value (AOV)
- Profit Margin
- Products Sold (quantity)
- Total Orders
- Monthly Sales Trend
- Sales by State Map
- Top 10 Products by Sales
- Sales by Category
- Sales by Region

## Key Findings
- Total sales: approximately $2.30 million.
- Total profit: approximately $286,397.
- Total orders: 5,009.
- Profit margin: approximately 12.47%.
- Technology, Furniture, and Office Supplies can be compared by sales performance.
- The dashboard provides a view of differences in sales across states and regions.
